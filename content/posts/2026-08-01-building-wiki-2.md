## 서론
드디어 위키 사이트 만들기 두번째 글로 돌아왔습니다. 첫 글 이후 한달이 넘게 지났네요. 역시 [꾸준히 글을 쓴다는건 너무나 어렵습니다.](/posts/documenting-is-hard)  
그새 저의 [k-meme 위키](<https://k-meme.wiki>) 사이트는 문서가 꽤 많이 늘었습니다. 아직은 모두 제가 작성한 문서지만요.. 많은 관심 부탁드립니다.

## 미디어위키 초기 설정
[지난글](/posts/building-wiki-1)에 이어, 이번 글에서 설명드릴 내용은 미디어 위키 초기 설정입니다. 앞선 내용으로 서버에 미디어위키를 설치하고 Nginx를 통해 서비스 할 수 있도록 했는데요, 바로 위키 사이트를 사용할 수 있는 것은 아닙니다. 설정한 도메인을 통해 사이트에 접속을 해서 처음 만나는 화면은 아래와 같습니다.

![설치첫화면](/images/2026/07/wiki-setup-01-full.png)

미디어위키 설치 위치에 **LocalSettings.php** 파일이 없을 때 나타나는 초기 화면인데요, 하단의 링크를 누르면 설정 마법사가 나타나고 초기 설정을 진행할 수 있습니다.

### 언어 설정 및 약관 동의
![언어설정](/images/2026/07/wiki-setup-02.png)

미디어위키 설정 마법사 화면입니다. 버전마다 모습이 다를 수 있습니다. 맨 처음 설정은 언어 설정입니다. 설치를 진행할 언어와 위키 사이트에서 사용할 언어를 선택합니다.

![약관동의](/images/2026/07/wiki-setup-03.png)

다음 화면에서 미디어위키가 설치된 환경을 검사하고, 문제가 없다면 사용약관 동의와 함께 다음 설정으로 넘어갈 수 있습니다.

### DB 설정
![DB설정](/images/2026/07/wiki-setup-04-db.png)

미디어위키를 설치하면서 생성했던 Database 정보를 입력합니다. 저의 경우에는 MariaDB를 사용했습니다. DB 설정 내용이 기억나지 않는다면 서버에서 아래 명령어로 확인할 수 있습니다.
``` bash
mysql -u root -p
```
``` sql
-- 전체 계정 목록 확인
SELECT User, Host FROM mysql.user;

-- 특정 계정 상세 확인
SHOW GRANTS FOR 'username'@'host';
```

### 관리 계정과 위키 권한 설정
![관리계정](/images/2026/07/wiki-setup-05-user.png)

다음 화면에서는 위키 이름을 설정하고, 위키를 관리할 관리 계정을 생성합니다. 설정을 마친 후에는 위키 사이트에서 해당 계정으로 로그인하여 추가 설정을 할 수 있습니다. 미디어위키는 사용자 계정 기반으로 권한 레벨을 설정할 수 있습니다.

![권한설정](/images/2026/07/wiki-setup-06-access.png)

위키의 접근 권한을 설정합니다. **열린 위키**는 로그인하지 않은 사용자도 문서를 편집할 수 있고, **계정 만들기 필요**는 사용자가 회원가입을 하고 로그인을 해야 문서를 편집할 수 있습니다. **승인된 편집자만**을 선택하면 관리자가 편집권한을 부여한 회원만 문서를 편집할 수 있고, **비공개 위키**는 관리자만 문서를 작성, 편집하고 다른 사용자는 읽기만 가능합니다.  
권한 설정부터는 초기 설정을 마치고 나서도 나중에 재설정이 가능합니다.

### E-mail 사용설정
![email사용설정](/images/2026/07/wiki-setup-07-email.png)

위키에서 이메일 사용을 활성화 할지를 설정합니다. 발신 이메일을 활성화하면 다른 사용자가 회원 가입을 할 때 자동으로 인증메일을 보내거나, 주시하는 문서가 편집됐을 때 알림을 보내는 등의 동작을 할 수 있습니다. 하지만 이메일 기능을 활성화하려면 서버에서도 설정해야 하는 부분들이 있어서 이메일 설정에 관해서는 추후 별도의 글을 작성하도록 하겠습니다.

### 스킨 및 확장 설치
미디어위키는 **스킨** 설치를 통해 사이트 테마를 설정할 수 있습니다.

![스킨설정](/images/2026/07/wiki-setup-08-skin.png)

위 화면에는 설정 마법사가 기본으로 제공하는 스킨들인데요, **자세한 정보** 링크로 들어가면 설정 마법사에는 없는 다른 스킨들도 구경할 수 있습니다. 추가 스킨 설치는 마법사 종료 이후에 서버에서 설정할 수 있습니다. 참고로 [k-meme 위키](<https://k-meme.wiki>)는 **Liberty**라는 스킨을 사용하고 있습니다.

![extension설정](/images/2026/07/wiki-setup-09-extensions.png)

위키에서 사용할 확장 기능들을 설치할 수 있습니다. 확장들도 스킨과 마찬가지로 마법사 종료 이후에 추가 설치를 할 수 있습니다. 일단 저는 초기에는 Claude가 추천하는 대로 설치를 진행하고, 관리하면서 필요한 확장은 그때그때 설치하고 있습니다.

### 파일 올리기 설정
![파일올리기설정](/images/2026/07/wiki-setup-10-fileupload.png)

위키에서 파일 업로드를 허용할지를 설정합니다. 보안을 강화하려면 사이트를 통한 파일 업로드는 막아두는게 안전하지만, 아무래도 그림이나 다른 자료를 올릴 수 없다면 문서가 재미없겠죠. 저는 초기 설정에서는 막았다가 추후에 최소한의 확장자들만 허용하는 것으로 변경했습니다. 외부 리소스만으로 작성하는데는 한계가 있더라구요.

### 로고 설정
![로고설정](/images/2026/07/wiki-setup-11-logo.png)

위키 사이트에 사용할 로고 이미지를 업로드합니다. 하지만 스킨에 따라서는 여기서 설정한 로고를 사용하지 않는 경우도 있어서 일단 별도의 이미지를 올리지 않고 넘어갔습니다.

### 설정 마무리
![설치중](/images/2026/07/wiki-setup-12-install.png)

설정의 마무리 단계입니다. 추가 설치가 필요한 파일들이 다운로드 되고 설정 마법사가 종료됩니다.

![setting파일다운로드](/images/2026/07/wiki-setup-13-download.png)

설정을 마치게 되면 **LocalSettings.php** 파일이 다운로드 됩니다. 다운로드한 파일을 미디어위키가 설치된 root 위치에 업로드하고 다시 설정한 도메인에 접속하면, 드디어 내가 만든 위키의 화면을 만나볼 수 있습니다.  
생성된 LocalSettings.php 파일을 열어보면 생성한 관리계정의 비밀번호가 그대로 들어가있는걸 볼 수 있는데요, 뭔가 찝찝하지만 Claude의 답변으로는 해당파일이 직접 노출될 일은 없으니 안전하다고 하네요.. 뭐 일단 믿어보기로 합니다. 그래도 혹시 모르니 다른 사이트 계정과는 다른 비밀번호를 사용하는게 좋겠습니다.

## 마치며
마법사를 통한 초기 설정은 끝났지만, **LocalSettings.php** 파일 편집을 통해 이후에도 설정을 변경할 수 있습니다. 저도 [k-meme 위키](<https://k-meme.wiki>) 사이트를 관리하며 추가 확장 설치나 권한 설정을 위해 수시로 LocalSettings.php 파일을 수정하고 있습니다. 다음 작성할 글들에서는 주로 사이트를 관리하며 만난 문제와 어떤 추가설정을 했는지를 설명해보겠습니다. 두번째 글을 쓰기까지도 한달이 넘는 시간이 걸렸는데, 다음 글은 또 언제 쓸지 모르겠네요.. ㅎㅎ 하지만 최대한 빨리 돌아오도록 하겠습니다. 그럼 안녕!
