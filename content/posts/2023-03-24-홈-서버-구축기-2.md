<p class="has-large-font-size">
  3. Ubuntu 보안 강화
</p>

<ul class="wp-block-list">
  <li>
    ssh port 변경 <ul class="wp-block-list">
      <li>
        <a href="https://nitr0.tistory.com/327?category=836159" target="_blank" rel="noreferrer noopener">https://nitr0.tistory.com/327?category=836159</a>
      </li>
      <li>
        <a href="http://yeopbox.com/우분투ubuntu-22-04-server-ssh-포트-변경-및-적용기/" target="_blank" rel="noreferrer noopener">http://yeopbox.com/우분투ubuntu-22-04-server-ssh-포트-변경-및-적용기/</a>

    </ul>
  </li>
</ul>

<pre class="wp-block-code has-black-color has-cyan-bluish-gray-background-color has-text-color has-background"><code>&lt;strong>  $ ssh &lt;username&gt;@&lt;ip&gt; -p &lt;port&gt;&lt;/strong></code></pre>

<ul class="wp-block-list">
  <li>
    service 이름(ssh)에 mapping된 port 번호 수정
  </li>
</ul>

<pre class="wp-block-code has-black-color has-cyan-bluish-gray-background-color has-text-color has-background"><code>&lt;strong>  $ sudo vi /etc/services&lt;/strong></code></pre>

<ul class="wp-block-list">
  <li>
    설정 적용을 위한 재시작
  </li>
</ul>

<pre class="wp-block-code has-black-color has-cyan-bluish-gray-background-color has-text-color has-background"><code>&lt;strong>  $ service ssh restart
  $ sudo reboot&lt;/strong></code></pre>

<ul class="wp-block-list">
  <li>
    방화벽 활성화 <ul class="wp-block-list">
      <li>
        <a href="https://nitr0.tistory.com/326" target="_blank" rel="noreferrer noopener">https://nitr0.tistory.com/326</a>
      </li>
      <li>
        ufw 설치 (Ubuntu 설치 시, 기본으로 포함되어있을 수 있음)
      </li>
      <li>
        활성화 하지 않음면 기본으로 꺼져있음
      </li>
    </ul>
  </li>
</ul>

<pre class="wp-block-code has-black-color has-cyan-bluish-gray-background-color has-text-color has-background"><code>&lt;strong>  $ sudo apt-get install ufw&lt;/strong></code></pre>

<ul class="wp-block-list">
  <li>
    수정된 port를 허용하고 기본 ssh port인 22번을 제한
  </li>
  <li>
    ssh 서비스 허용
  </li>
</ul>

<pre class="wp-block-code has-black-color has-cyan-bluish-gray-background-color has-text-color has-background"><code>&lt;strong>  $ sudo ufw allow &lt;port&gt;
  $ sudo ufw allow ssh
  $ sudo ufw deny 22&lt;/strong></code></pre>

<ul class="wp-block-list">
  <li>
    ufw 활성화
  </li>
</ul>

<pre class="wp-block-code has-black-color has-cyan-bluish-gray-background-color has-text-color has-background"><code>&lt;strong>  $ sudo ufw enable&lt;/strong></code></pre>

<ul class="wp-block-list">

<p class="has-large-font-size">
  4. 외부로 port 열기 (port fowarding)
</p>

<mark style="background-color:rgba(0, 0, 0, 0)" class="has-inline-color has-luminous-vivid-orange-color">**※ 주의: port fowarding을 적용하면 즉시 서버가 외부에 노출되므로 반드시 보안강화를 먼저 진행한 후 port를 열어준다.**</mark>

<ul class="wp-block-list">
  <li>
    우리집 공인 IP 확인 <ul class="wp-block-list">
      <li>
        Server와 같은 공유기에 연결된 PC에서 네이버 접속 <ul class="wp-block-list">
          <li>
            네이버 검색창에 내 아이피 검색
          </li>
          <li>
            또는 Ubuntu server에서 아래의 명령어 입력
          </li>
        </ul>
      </li>
    </ul>
  </li>
</ul>

<pre class="wp-block-code has-black-color has-cyan-bluish-gray-background-color has-text-color has-background"><code>&lt;strong>  $ curl ifconfig.me&lt;/strong></code></pre>

<ul class="wp-block-list">
  <li>
    공유기 설정에서 port forwarding <ul class="wp-block-list">
      <li>
        NETGEAR 제품의 경우 설정 주소는&nbsp;<strong>192.168.1.1</strong>
      </li>
      <li>
        고급 설정에서 포트포워딩 설정 가능
      </li>
    </ul>
  </li>
</ul><figure class="wp-block-image size-full">

<img loading="lazy" decoding="async" width="978" height="236" src="https://rammie-blog.xyz/images/2023/03/netgear1.png" alt="" class="wp-image-52" srcset="https://rammie-blog.xyz/images/2023/03/netgear1.png 978w, https://rammie-blog.xyz/images/2023/03/netgear1-300x72.png 300w, https://rammie-blog.xyz/images/2023/03/netgear1-768x185.png 768w" sizes="auto, (max-width: 978px) 100vw, 978px" /> </figure> 

<ul class="wp-block-list">
  <li>
    서비스 이름은 단순 구분을 위한 이름이므로 아무거나 선택
  </li>
  <li>
    내부 IP 주소에 server의 local IP를 입력하고 추가 버튼 클릭
  </li>
  <li>
    추가된 항목 선택하여 세부 설정
  </li>
</ul><figure class="wp-block-image size-large">

<img loading="lazy" decoding="async" width="1024" height="277" src="https://rammie-blog.xyz/images/2023/03/netgear2-1024x277.png" alt="" class="wp-image-53" srcset="https://rammie-blog.xyz/images/2023/03/netgear2-1024x277.png 1024w, https://rammie-blog.xyz/images/2023/03/netgear2-300x81.png 300w, https://rammie-blog.xyz/images/2023/03/netgear2-768x208.png 768w, https://rammie-blog.xyz/images/2023/03/netgear2.png 1182w" sizes="auto, (max-width: 1024px) 100vw, 1024px" /> </figure> 

<ul class="wp-block-list">
  <li>
    서비스 종류는 TCP 선택
  </li>
  <li>
    외부와 내부 동일한 포트 범위 사용을 선택하고, ssh용으로 변경한 포트번호 입력
  </li>
  <li>
    <strong><mark style="background-color:rgba(0, 0, 0, 0)" class="has-inline-color has-luminous-vivid-orange-color">이제 공인 IP를 통해 어디서든 집에 있는 server에 접속할 수 있다.</mark></strong>
  </li>
</ul>

<pre class="wp-block-code has-black-color has-cyan-bluish-gray-background-color has-text-color has-background"><code>&lt;strong>  $ ssh &lt;username&gt;@&lt;공인ip&gt; -p &lt;port&gt;&lt;/strong></code></pre>
