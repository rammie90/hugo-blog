## ✅ 1. **RSI + 볼린저 밴드 반전 전략 (Mean Reversion)** {.wp-block-heading}

### 📌 개념: {.wp-block-heading}

<ul class="wp-block-list">
  <li>
    <strong>과매도 + 하단 밴드 이탈 시 매수</strong>, 평균 회귀 노림
  </li>
  <li>
    횡보장이 많고 급락 후 반등이 자주 나오는 코인 시장에 적합
  </li>
</ul>

### 🔧 조건: {.wp-block-heading}

<ul class="wp-block-list">
  <li>
    <strong>RSI(14) < 25</strong>
  </li>
  <li>
    <strong>가격이 Bollinger Band 하단보다 아래</strong>
  </li>
  <li>
    손절: -3%, 익절: +5%
  </li>
</ul>

### 📈 실전 예시 (BTCUSDT, 1h): {.wp-block-heading}

<pre class="wp-block-code"><code>&lt;code># pseudocode
if RSI &lt; 25 and Close &lt; BB_lower:
    buy()
    set_stop_loss(-3%)
    set_take_profit(+5%)
</code>&lt;/code></pre>

### ✅ 장점: {.wp-block-heading}

<ul class="wp-block-list">
  <li>
    잦은 거래 X → 수수료 부담 낮음
  </li>
  <li>
    반등 포착 확률 높음
  </li>
</ul>

### ⚠️ 리스크: {.wp-block-heading}

<ul class="wp-block-list">
  <li>
    급락장에서는 손절 연속 가능
  </li>
  <li>
    추세장이면 손익비 나쁨 → 필터링 필요 (예: ADX)
  </li>
</ul>

<hr class="wp-block-separator has-alpha-channel-opacity" />

## ✅ 2. **모멘텀 돌파 전략 (Trend Following)** {.wp-block-heading}

### 📌 개념: {.wp-block-heading}

<ul class="wp-block-list">
  <li>
    강한 상승 추세 초입에서 매수 → 추세 유지 시 지속 수익
  </li>
  <li>
    뉴스/ETF 수혜 시기, 펌핑 장에 적합
  </li>
</ul>

### 🔧 조건: {.wp-block-heading}

<ul class="wp-block-list">
  <li>
    <strong>가격이 20일 고점 돌파</strong>
  </li>
  <li>
    <strong>거래량이 최근 20일 평균의 1.5배 이상</strong>
  </li>
  <li>
    익절: +10~20%, 손절: -5%
  </li>
</ul>

### 📈 실전 예시: {.wp-block-heading}

<pre class="wp-block-code"><code>&lt;code>if Close > max(High&#91;-20:]) and Volume > avg(Volume&#91;-20:]) * 1.5:
    buy()
    set_trailing_stop(7%)
</code>&lt;/code></pre>

### ✅ 장점: {.wp-block-heading}

<ul class="wp-block-list">
  <li>
    추세장이면 큰 수익
  </li>
  <li>
    백테스트로 승률 낮아도 손익비로 극복 가능
  </li>
</ul>

### ⚠️ 리스크: {.wp-block-heading}

<ul class="wp-block-list">
  <li>
    횡보장에선 연속 손절 가능 → 필터링 필수
  </li>
</ul>

## ✅ 3. **김프/역프 차익거래 (Arbitrage)** {.wp-block-heading}

### 📌 개념: {.wp-block-heading}

<ul class="wp-block-list">
  <li>
    <strong>업비트 vs 바이낸스 간 가격 차이</strong> 발생 시 매수/매도
  </li>
</ul>

### 예: {.wp-block-heading}

<ul class="wp-block-list">
  <li>
    BTC 바이낸스 가격: 1000만 원
  </li>
  <li>
    업비트 가격: 1020만 원 (2% 김프)
  </li>
  <li>
    바이낸스에서 매수 + 업비트로 전송 후 매도
  </li>
</ul>

### ✅ 장점: {.wp-block-heading}

<ul class="wp-block-list">
  <li>
    원칙적으로 무위험 (전송 지연 제외)
  </li>
  <li>
    반복 가능 시 고수익
  </li>
</ul>

### ⚠️ 리스크: {.wp-block-heading}

<ul class="wp-block-list">
  <li>
    <strong>전송 지연 중 가격 역전</strong> 시 손실
  </li>
  <li>
    <strong>자금 회전이 느림</strong>
  </li>
  <li>
    업비트는 <strong>법정화폐 출금 제한 시간 있음</strong>
  </li>
</ul>
